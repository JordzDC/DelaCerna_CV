# Jorodz Dela Cerna | Personal CV

## Short Description

A responsive personal CV and portfolio website for Jorodz Dela Cerna, a Bachelor of Science in Information Technology student at Davao del Norte State College. It showcases his profile, education, skills, projects, certificates, experience, and contact information, with light and dark themes and mobile-friendly navigation.

- HTML5 — page structure and content
- CSS3 — styling, responsive layouts, and animations
- JavaScript — theme switching, navigation, scroll effects, and contact form validation
- Google Fonts — Space Grotesk, Inter, and JetBrains Mono typography
- Remix Icon — interface and social media icons
